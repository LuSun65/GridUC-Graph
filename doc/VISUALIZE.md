# 电力系统网络可视化方案

## 目标

将电力系统表示为节点与连接线组成的网络，并实现以下功能：

- 根据线路总阻抗决定连接线在图上的期望长度；
- 调整节点颜色和连接线颜色；
- 自动排列节点并减少节点重叠；
- 支持拖动节点进行人工调整；
- 保存调整后的布局和颜色。

这里的“线路长度”指可视化画面中的显示长度，不代表线路的实际物理长度。无需根据导线型号、单位阻抗或电压等级换算实际公里数。

## 工具选择

### 前端

使用 **Cytoscape.js** 绘制网络。它适合节点—连接线结构，并支持：

- 节点拖动与选择；
- 动态调整节点和连接线的颜色、大小及样式；
- 点击查看节点或线路属性；
- 多种自动布局算法；
- 导入和导出 JSON 数据。

### 布局算法

使用 **fCoSE** 布局。它可以把每条线路的总阻抗设置为期望显示长度，并在此基础上自动排列整个网络。

- 阻抗越小，期望连接线越短；
- 阻抗越大，期望连接线越长；
- 布局算法同时处理节点排斥、重叠和整体可读性。

自动布局只能尽量接近期望长度。电网中存在环路或一个节点连接多条线路时，所有连接线通常无法同时严格达到指定长度。

### 数据格式

使用 **JSON** 保存：

- 节点编号和名称；
- 线路的起点、终点和总阻抗；
- 节点与连接线颜色；
- 节点位置；
- 可选的标签、线宽和其他显示属性。

### 后端与存储

第一版可以不使用后端，直接由前端读取和导出 JSON。

需要长期保存、多人使用或集中管理数据时，再增加：

- **FastAPI**：提供网络数据的读取和保存接口；
- **SQLite**：保存节点、线路、颜色和布局位置。

本需求不需要 pandapower。只有以后需要潮流、母线电压、线路负载率或越限分析时，才有必要引入电力计算工具。

## 操作流程

1. 将电力网络整理为节点和线路数据。
2. 为每条线路记录起点、终点和总阻抗。
3. 统计阻抗范围，将阻抗映射到合理的屏幕显示长度范围。
4. 限制最短和最长显示长度，防止极端阻抗导致网络过度收缩或拉伸。
5. 使用 Cytoscape.js 加载网络数据。
6. 使用 fCoSE 按线路的期望长度自动排列节点。
7. 允许用户选择节点或连接线，并通过颜色选择器修改颜色。
8. 开启节点拖动，让用户对自动布局结果进行人工微调。
9. 保存节点位置、节点颜色和连接线颜色，避免重新打开后丢失调整结果。

## 推荐实施顺序

1. 先完成 JSON 数据导入和基本网络显示。
2. 接入 fCoSE，并实现总阻抗到显示长度的映射。
3. 增加节点与连接线的选择、改色和拖动功能。
4. 增加布局与样式的 JSON 导出、导入功能。
5. 确有集中存储需求时，再接入 FastAPI 和 SQLite。

## 最终方案

- 网络绘制：Cytoscape.js
- 自动布局：fCoSE
- 数据交换：JSON
- 初期后端：不需要
- 后续可选后端：FastAPI
- 后续可选存储：SQLite
